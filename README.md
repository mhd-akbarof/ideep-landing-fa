# iDeep landing page

Static Next.js export served by Nginx.

## Deploy with Dokploy

1. Create an **Application** and connect this GitHub repository.
2. Select **Dockerfile** as the build type. The Dockerfile path is `Dockerfile`.
3. Set the container port to `80`.
4. Add the domain and enable HTTPS in Dokploy.
5. Deploy. No environment variables are required.
